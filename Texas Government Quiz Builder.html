    Export to Canvas

    Import as
    Options
    Importing
    1. In your course: Settings → Import Course Content.
    2. Content type: QTI .zip file. Choose the downloaded file and click Import.
    3. The quiz appears under Quizzes (Classic Quizzes), unpublished. Short-answer items import as essay questions you grade by hand.
    4. Using New Quizzes? Create a quiz, then use ⋮ → Import Content and pick the same file, or migrate the classic quiz.

    Print or save as PDF

    Print
    Form A keeps your order. Other forms shuffle question order and answer choices, each with its own key.
    Include

    Your browser's print dialog opens next. Choose Save as PDF to keep a file.

    Student practice link

    Students open the link and work through the set one question at a time. Answers and rationales appear only after they commit to a choice, and choices reshuffle on every attempt. Nothing is graded or recorded.

    Paste it into a Canvas page, announcement, or module item. The questions travel inside the link itself, so it keeps working even if you change this quiz later.
